LOCAL SETUP

Connect 9Router

The web app talks to 9Router through this local server. Keep your key in the project’s ignored .env file; it is never sent to the browser.

ROUTER_BASE_URL=http://127.0.0.1:20128 ROUTER_API_KEY=your-9router-key
  1. Copy .env.example to .env.
  2. Set ROUTER_API_KEY to the key configured in 9Router.
  3. Restart Personal Workspace after changing the file.
◈ Never commit .env.
